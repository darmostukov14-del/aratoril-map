# Карта Араторила (Telegram Mini App)

## Как запустить

1. Загрузи папку `webapp` на любой хостинг с HTTPS:
   - Render.com
   - Railway.app
   - Vercel
   - Netlify
   - GitHub Pages (если настроишь)

2. Получи публичную ссылку вида `https://что-то.onrender.com`

3. Пропиши эту ссылку в `.env` бота:

```env
WEBAPP_URL=https://твоя-ссылка
```

4. Перезапусти бота.

5. В боте появится кнопка **«🗺️ Карта Араторила»**.

## Что умеет карта сейчас

- Показывает реальный Армавир (центр: 44.997655, 41.129644)
- Можно нажать «Оставить Свиток здесь» — точка сохраняется
- Чем больше точек, тем сильнее «отступает Туман» (процент уменьшается)
- Точки пока хранятся локально в браузере (в следующей версии будут на сервере)
